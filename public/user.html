📑 Developer API Docs & SDK Integration

Integrate dynamic UPI QR payments into your website, mobile app, or e-commerce storefront in under 2 minutes.

POST /api/v1/orders (Generate Dynamic QR Code)

Creates a new payment order with unique paise offset, dynamic UPI URI, high-res Base64 QR code image, and mobile intent links.

cURL Request 
curl -X POST http://localhost:3000/api/v1/orders \
  -H "Content-Type: application/json" \
  -H "x-api-key: pg_live_..." \
  -d '{
    "amount": 250.00,
    "customerName": "Rahul Verma",
    "customerPhone": "9876543210",
    "webhookUrl": "https://yourwebsite.com/api/payment-webhook"
  }'
Node.js / Express 
const response = await fetch('http://localhost:3000/api/v1/orders', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'x-api-key': 'pg_live_...'
  },
  body: JSON.stringify({
    amount: 250.00,
    customerName: 'Rahul Verma',
    customerPhone: '9876543210',
    webhookUrl: 'https://yourwebsite.com/api/payment-webhook'
  })
});

const data = await response.json();
console.log('Order Code:', data.order.orderCode);
console.log('QR Image (Base64):', data.order.qrDataUrl);
console.log('Checkout URL:', data.order.checkoutUrl);
Python (Requests) 
import requests

url = "http://localhost:3000/api/v1/orders"
headers = {
    "Content-Type": "application/json",
    "x-api-key": "pg_live_..."
}
payload = {
    "amount": 250.00,
    "customerName": "Rahul Verma",
    "webhookUrl": "https://yourwebsite.com/api/payment-webhook"
}

response = requests.post(url, json=payload, headers=headers)
order = response.json().get("order")
print("Order Code:", order.get("orderCode"))
print("Payable Amount:", order.get("amount"))
PHP (cURL) 
<?php
$ch = curl_init('http://localhost:3000/api/v1/orders');
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    'Content-Type: application/json',
    'x-api-key: pg_live_...'
]);
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode([
    'amount' => 250.00,
    'customerName' => 'Rahul Verma'
]));

$response = curl_exec($ch);
curl_close($ch);
$data = json_decode($response, true);
echo "Order: " . $data['order']['orderCode'];
?>
