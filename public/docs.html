Developer API Reference

Integrate direct NPCI Bharat UPI payments into your eCommerce store, SaaS, or custom website in minutes with automated email and push reconciliation.

1. Authentication

All merchant API requests require your API Key passed in the x-api-key request header or Authorization: Bearer <api_key>.

// Example Header
x-api-key: pg_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

You can find and regenerate your Production API Key in your Merchant Dashboard.

2. Create Payment Order

Initiates a dynamic UPI payment session. Generates a collision-safe payable amount and QR code.

POST /api/v1/orders
Field Type Required Description
amount Number Yes Amount in INR (e.g. 500.00).
customerName String No Name of the customer.
customerPhone String No 10-digit mobile number.
webhookUrl String No HTTPS webhook callback URL for payment notifications.
expiryMinutes Number No Order validity window (default 20, max 1440).

Example Request:

curl -X POST https://yourgateway.com/api/v1/orders \
  -H "Content-Type: application/json" \
  -H "x-api-key: pg_live_your_api_key_here" \
  -d '{
    "amount": 499.00,
    "customerName": "Rahul Verma",
    "customerPhone": "9876543210",
    "webhookUrl": "https://myshop.com/api/payment-webhook"
  }'

Example Response:

{
  "success": true,
  "order": {
    "orderCode": "ORD-AB12CD",
    "amount": 499.02,
    "baseAmount": 499.00,
    "status": "PENDING",
    "checkoutUrl": "/checkout/ORD-AB12CD",
    "fullCheckoutUrl": "https://yourgateway.com/checkout/ORD-AB12CD",
    "upiUri": "upi://pay?pa=merchant@upi&pn=Store&am=499.02&tr=ORD-AB12CD",
    "qrDataUrl": "data:image/png;base64,iVBORw0KGgo...",
    "expiresAt": 1728984000000
  }
}

3. Check Order Status

Poll or query order status in real time.

GET /api/v1/orders/:orderCode 
curl https://yourgateway.com/api/v1/orders/ORD-AB12CD
{
  "success": true,
  "order": {
    "orderCode": "ORD-AB12CD",
    "status": "PAID",
    "amount": 499.02,
    "utr": "428719284910",
    "paidAt": 1728983500000,
    "sender": "Rahul Verma"
  }
}

4. Webhook Verification & Security

When a payment is matched and confirmed, the gateway sends an HTTP POST request to your webhookUrl signed with HMAC-SHA256.

// Signature Header
X-Gateway-Signature: sha256=<hmac_sha256_hash>

// Webhook Payload
{
  "event": "payment.success",
  "timestamp": 1728983505000,
  "data": {
    "orderCode": "ORD-AB12CD",
    "amount": 499.02,
    "status": "PAID",
    "utr": "428719284910",
    "sender": "Rahul Verma",
    "paidAt": 1728983500000
  }
}
